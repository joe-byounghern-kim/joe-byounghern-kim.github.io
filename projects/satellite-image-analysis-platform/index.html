Satellite Image Analysis Platform

Frontend work on SI Analytics' AI-powered satellite image analysis platform, including map workflows, large-file upload, and administrative tools.

Context and role

I worked as a Frontend Engineer on SI Analytics’ AI-powered satellite image analysis platform for intelligence-agency operations. The platform project ran from April 2022 to September 2024 (2.5 years); I stayed at SI Analytics until January 2025.

Product and team scope

The platform combined AI-result visualization, analysis tools, and quality checks for AI-generated results.

The team moved from a chapter-based structure to focused product development. The frontend team grew from six to up to eight developers within a 23+ person group:

  • 6 Frontend Engineers
  • 6 Backend Engineers
  • 3 ML Engineers
  • 1 Test Engineer
  • 4 Designers
  • 3 Product Managers

Delivery included a waterfall process for business requirements and Critical Design Reviews.

Frontend contribution

The product team implemented 400+ functional requirements across the platform. This was the team’s delivery scope. My frontend contributions included feature integration and user-flow work in the following areas:

  • Area of Interest (AoI) management for geospatial regions
  • AI Pack management for AI-model lifecycle work
  • Administrative tools for announcements, issue reporting, error logs, and permissions
  • Satellite-image large-file upload
  • The Object Catalog, homepage and dashboard, archive, authentication and login, and application settings

Technical approach

The stack combined React with Redux state management, TypeScript, OpenLayers for geospatial visualization, gRPC and Axios for API communication, React-DND for drag and drop, and React Query for server state.

The integration work included class-based geospatial logic, custom hooks for UI state, and event-handler and useEffect optimization.

Outcomes

The integrated solution was formally assessed at Technology Readiness Level (TRL) 9.

My frontend work helped make this technically complex product easier to use, from map interactions and visualization to browser uploads that let users keep working during large transfers.

Related implementation notes

  • Reducing OpenLayers map render time by 51%
  • Uploading large satellite images while keeping the web app usable
  • Testing difficult React components with data snapshots
